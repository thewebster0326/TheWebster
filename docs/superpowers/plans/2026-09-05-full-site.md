# thewebster.net Full Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the live coming-soon page at thewebster.net with a full 7-section static marketing site (Home, Services, Portfolio, Process, About, Blog, Contact) for The Webster's international expansion.

**Architecture:** Static HTML/CSS/JS, no build step, no framework — matches the existing (already deployed) coming-soon page and the agency's other static client sites (e.g. Optique Borehole Drilling). Every page is a standalone `.html` file sharing one `styles.css` and one `script.js`, with header/nav/footer markup duplicated per page. Deploys via the existing cPanel Git Version Control pipeline (`.cpanel.yml`, already working).

**Tech Stack:** Plain HTML5, CSS (custom properties, flexbox/grid, `prefers-reduced-motion`), vanilla JS (`IntersectionObserver` for scroll reveal, no libraries), PHP `mail()` for the contact form (mirrors the working `contact-handler.php` pattern already live on Optique Borehole Drilling's site). Fonts: Space Grotesk (display), Inter (body), JetBrains Mono (labels/eyebrows) via Google Fonts, already linked in the existing pages.

## Global Constraints

- No build step, no JS framework, no CMS — every page is hand-authored static HTML (per spec Non-goals).
- No public pricing anywhere — every CTA is "Get a Quote" linking to `contact.html` (per spec Goals).
- No fabricated testimonials, reviews, or client quotes anywhere on the site (per spec Non-goals).
- No personal founder photo/bio on the About page — company-level framing only, built around the user-provided mission statement verbatim (per spec Non-goals).
- No phone number or WhatsApp anywhere on this site — the international arm uses contact form + email only (per the user's explicit choice; do not copy Optique's phone/WhatsApp FAB pattern).
- Brand tokens (already defined in `styles.css`, do not change): `--ink: #0a0d16`, `--surface: #12172a`, `--blue: #2e6ff2`, `--violet: #8b2ff0`, `--orange: #ff7a2e`, `--text: #f5f6fa`, `--muted: #8a93b3`, `--gradient: linear-gradient(100deg, var(--blue) 0%, var(--violet) 55%, var(--orange) 100%)`.
- Fonts: `'Space Grotesk', sans-serif` for headings/eyebrows, `'Inter', system-ui, sans-serif` for body text, `'JetBrains Mono', monospace` for eyebrows/labels/nav caps — already linked via Google Fonts `<link>` tags in `index.html`; every new page must include the same `<link>` tags.
- Every animated/transitioning element must be neutralized under `@media (prefers-reduced-motion: reduce)` (per spec Testing/QA plan).
- Contact form destination is `info@thewebster.net` (per spec) — flagged in DEPLOY.md as requiring manual cPanel mailbox creation, not something any task here can verify by itself.

- [ ] **Step 2: Create `script.js`**

```javascript
document.addEventListener('DOMContentLoaded', () => {

  const navToggle = document.getElementById('navToggle');
  const mainNav = document.getElementById('mainNav');

  if (navToggle && mainNav) {
    navToggle.addEventListener('click', () => {
      const isOpen = mainNav.classList.toggle('open');
      navToggle.setAttribute('aria-expanded', String(isOpen));
    });

    mainNav.querySelectorAll('a').forEach((link) => {
      link.addEventListener('click', () => {
        mainNav.classList.remove('open');
        navToggle.setAttribute('aria-expanded', 'false');
      });
    });
  }

  const params = new URLSearchParams(window.location.search);
  if (params.get('sent') === '1') {
    const note = document.querySelector('.form-success');
    if (note) note.classList.add('visible');
  }

  const revealTargets = document.querySelectorAll('.reveal');
  if ('IntersectionObserver' in window && revealTargets.length) {
    const observer = new IntersectionObserver((entries) => {
      entries.forEach((entry) => {
        if (entry.isIntersecting) {
          entry.target.classList.add('in-view');
          observer.unobserve(entry.target);
        }
      });
    }, { threshold: 0.15 });

    revealTargets.forEach((el) => observer.observe(el));
  } else {
    revealTargets.forEach((el) => el.classList.add('in-view'));
  }

});
```

- [ ] **Step 2: Write `contact-handler.php`**

```php
<?php
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    header('Location: contact.html');
    exit;
}

$honeypot = trim($_POST['website'] ?? '');
$name = trim($_POST['name'] ?? '');
$email = trim($_POST['email'] ?? '');
$message = trim($_POST['message'] ?? '');

if ($honeypot !== '' || $name === '' || $email === '' || $message === '' || !filter_var($email, FILTER_VALIDATE_EMAIL)) {
    header('Location: contact.html?error=1');
    exit;
}

$to = 'info@thewebster.net';
$subject = 'New enquiry from thewebster.net';

$body = "New contact form enquiry:\n\n";
$body .= "Name: {$name}\n";
$body .= "Email: {$email}\n\n";
$body .= "Message:\n{$message}\n";

$safeEmail = str_replace(["\r", "\n"], '', $email);
$headers = "From: The Webster Website <info@thewebster.net>\r\n";
$headers .= "Reply-To: {$safeEmail}\r\n";

mail($to, $subject, $body, $headers);

header('Location: contact.html?sent=1');
exit;
```
